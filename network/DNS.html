DNS ​

什么是DNS ​

Domain Name System 域名解析系统，在网络中提供域名和IP地址之间互相解析的应用层服务。

域名->IP映射的意义 ​

  • 方便记忆：记住一位朋友的名字显然比记住他的身份证号要容易得多。对于一个网站来说IP相当于身份证号，而域名就相当于名字。域名更容易被用户记住，IP更适合计算机处理。
  • 灵活：IP可以动态变化，域名可以绑定多个IP。同时也为CDN服务提供基础。
  • 安全性：DNS服务商家提供可信的域名解析服务，防止用户的权益在非法网站上受到侵害。

DNS解析过程 ​

多级服务 ​

计算机网络中存在着诸多DNS服务器（多级缓存），从小到大：

  • 浏览器DNS缓存
  • 操作系统DNS缓存
  • 本地host文件
  • 本地DNS服务器（由ISP提供或手动配置，如 8.8.8.8）
  • 根DNS服务器（全球13组，管理顶级域名）
  • 顶级域名服务器（如 .com、.cn、.org）
  • 权威DNS服务器（域名购买处的DNS服务器，存储具体的域名解析记录）

递归查询 vs 迭代查询 ​

  • 递归查询：客户端向本地DNS服务器发起请求，本地DNS服务器负责完整地解析出结果并返回。如果本地DNS服务器没有缓存，它会代替客户端向其他DNS服务器继续查询，直到获得最终结果。客户端只需等待一个最终应答。

  • 迭代查询：本地DNS服务器向其他DNS服务器查询时，对方如果不知道最终答案，会返回"下一步应该去问谁"（即指向下一个更接近答案的DNS服务器），由本地DNS服务器自己去继续查询。大多数DNS服务器之间的查询采用迭代方式。

完整解析流程示例 ​

以解析 www.example.com 为例：

  1. 浏览器检查应用缓存，若有则直接使用
  2. 检查本地host文件（如 /etc/hosts），若有则直接使用
  3. 向本地DNS服务器发起递归查询
  4. 本地DNS服务器检查自身缓存，若有则返回
  5. 本地DNS服务器向根DNS服务器发起迭代查询，根服务器返回 .com 顶级DNS服务器地址
  6. 本地DNS服务器向顶级DNS服务器查询，顶级服务器返回 example.com 权威DNS服务器地址
  7. 本地DNS服务器向权威DNS服务器查询，权威服务器返回 www.example.com 的IP地址
  8. 本地DNS服务器将结果缓存并返回给客户端

域名配置 ​

  • 开发者在域名服务商购买的域名是顶级域名，域名服务商为购买的域名提供对应的解析服务。
  • 域名解析配置有多种类型
    • AAAA：ipv6
    • A：ipv4
    • CNAME：另一个域名
    • MX：邮件交换记录，指向邮件服务器
    • NS：域名服务器记录，指定由哪些DNS服务器来解析该域名
    • TXT：文本记录，常用于域名验证（如SPF、DKIM）
    • SRV：服务记录，指定提供特定服务的服务器地址和端口

大型分布式应用的DNS ​

  • 为了响应速度，IP是动态的，会根据运营商、用户所在地等信息将DNS解析到距离用户最近的服务器上（即DNS智能解析/GSLB）。
  • 根服务器不会暴露在公网上，用户能访问到的往往是反向代理服务器、防火墙服务器等。
  • CDN（内容分发网络）大量依赖DNS实现就近访问：用户请求域名时，DNS将域名解析为距用户最近的CDN节点IP。
  • DNS负载均衡：一个域名可以配置多个A记录，DNS服务器按照轮询等策略返回不同的IP，实现简单的负载均衡。

DNS安全 ​

  • DNS劫持：攻击者篡改DNS解析结果，将用户引导至恶意网站
  • DNS污染：在DNS查询过程中，伪造响应数据包返回错误的IP地址
  • DNSSEC：DNS安全扩展，通过数字签名验证DNS响应的真实性和完整性，防止DNS劫持和污染
